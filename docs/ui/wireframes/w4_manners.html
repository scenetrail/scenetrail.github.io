巡礼のマナー

舞台の多くは、人が暮らし、働いている場所です。

住宅地で

  • 私道・敷地・駐車場に入らない
  • 住民や家・車のナンバーを撮らない
  • 階段・歩道・道をふさいで撮らない。長く居座らない
  • 早朝・夜は声を小さく

神社・お寺で

  • 撮影が禁じられた所では撮らない
  • 参拝の人を優先する

駅・道路で

  • 線路や車道に出て撮らない
  • ホームでは他の人の通行をふさがない

お店で

  • 撮影は店の人に聞いてから

ごみ・騒音

  • ごみは持ち帰る
